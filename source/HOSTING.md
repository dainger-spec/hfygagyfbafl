# Europe Private Blacklist — хостинг

Нужен Node 20+.

## ВАЖНО: папка `data` на сервере

В `data/` лежат список чатов с рассылкой (`telegram-bindings.json`,
`telegram-relay-chats.json`), заявки, ID и доказательства. Файлы `data/` в
репозитории — только стартовые; рабочие данные живут на сервере.

- **Никогда не удаляйте и не заменяйте `data/` на сервере.**
- Перед каждым обновлением скачайте `data/` себе — это резервная копия.
- Бот сам делает ежедневные копии в `data/backups/` (30 дней).

## Обновление

1. Скачайте себе копию папки `data/` с сервера.
2. Остановите приложение.
3. Удалите на сервере папку `.output` и файл `dist-output.tgz`. Больше ничего не удаляйте.
4. Залейте файлы из этой папки (`dist-output.tgz`, `package.json`, `scripts/`, `public/`, `vite.config.mjs`, `HOSTING.md`).
5. В `.env` или в панели хоста:

```
TELEGRAM_BOT_TOKEN=ваш_токен
PUBLIC_URL=https://europe.bothost.tech
PORT=3000
DATA_DIR=./data
```

6. `npm run build`
7. `npm start`

После смены токена ничего дополнительно делать не нужно: при запуске бот сам
переустановит вебхук.

## Команды в чате судей

- `/admin` — панель управления на кнопках: сводка, заявки без решения,
  чаты рассылки (включить/выключить, проверить права бота), канал для постов
- `/relays` — список чатов рассылки
- `/relay_on -100…` — включить рассылку в чат вручную
- `/relay_off -100…` — выключить
- `/channel -100…` — сменить канал для постов

## Публикация заявки

1. «Опубликовать» → появятся кнопки «С рассылкой», «Без рассылки»,
   «✏ Изменить текст», «👁 Предпросмотр».
2. «✏ Изменить текст» → ответьте на сообщение бота новым текстом поста
   (жирный, курсив, ссылки сохраняются). Строки с аккаунтом/суммой и подпись
   Subscribe бот добавит сам. «↩ Вернуть исходный текст» отменяет правку.
3. Пост публикуется в канал (`/channel` или панель → «Канал для постов»),
   а в чаты рассылки бот пересылает уже пост из канала. Если в канале включена
   защита от пересылки, бот отправит в чаты копии.

## Рассылка пользователям бота

`/admin` → «📣 Рассылка пользователям бота»: количество пользователей и рассылка
только им в личные сообщения (в чаты и каналы она не уходит).

1. «✉ Новая рассылка» → ответьте на сообщение бота тем, что нужно разослать:
   текст, фото, видео, GIF, стикер или альбом, с форматированием.
   Премиум-эмодзи сохранятся, если у владельца бота есть Telegram Premium.
   Не удаляйте это сообщение до конца рассылки — бот копирует именно его.
2. Бот покажет предпросмотр. «➕ Добавить кнопки» → ответьте строками
   `Текст - https://ссылка`, кнопки в одном ряду через `|`.
3. «🚀 Разослать» → «✅ Да, разослать». Прогресс обновляется в чате, есть
   кнопка «⏹ Остановить». После перезапуска сервера рассылка продолжится,
   повторно никому не отправит.
